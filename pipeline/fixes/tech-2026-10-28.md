## Reporté

- **`<html lang="fr">` servi sur `/en`** (top action 2) : **build check requis + refonte structurelle**. Un fix propre suppose des root layouts multiples (route groups `(fr)` / `(en)` avec chacun leur `<html lang>`), donc le déplacement de tout l'arbre `app/` (admin, api, not-found, opengraph-image…). La variante via header de middleware + `headers()` rendrait toutes les pages dynamiques et casserait l'ISR/SSG. À faire **dans `emd-template-v2`** (racine commune), puis à reporter sur les sites. Le script client et le `<div lang="en">` restent en place en attendant.
- **`NEXT_PUBLIC_SITE_URL` sur Vercel** (top action 1) : non vérifiable depuis ce run (aucun accès aux settings Vercel). **Action humaine** : vérifier la variable sur le projet `fond-investissement`. Tant que `fonds-investissement.be` n'est pas acheté et branché, tous les canonicals et le sitemap pointent vers un domaine non servi.
- **hreflang FR sur `/simulateur` et `/deals`** : ces routes sont désactivées (`notFound()`, page 404 noindex au build). Leur ajouter un hreflang n'a aucun effet aujourd'hui : à faire à leur activation. Le miroir EN les déclare déjà.
- **`/[article]` (pages CMS racine FR)** : pas de miroir `app/en/[article]`. Pas de hreflang à émettre (doctrine : alternate uniquement si la traduction existe).
- Mineurs non traités : `lastModified` = date de build pour les pages hors articles dans le sitemap. hreflang catégories inconditionnel (sans effet aujourd'hui, 6/6 mirrorées).
