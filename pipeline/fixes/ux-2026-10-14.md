- **`ArticleView` voile `rgba(10,10,15,…)` + H1 `#fff`** : voile sur photo = chrome invariant ; à passer sur `--scrim-*` / `--chrome-text`.
- **`style.uiStyle: 'etiket'`** laissé tel quel : consommateurs non énumérables depuis la session (pas de recherche de code sur ce dépôt). `signature.components` mis à jour.
- **Valeurs de globals.css** (#1F4FB5 dans les 5 blocs) : désormais simples replis, écrasées par PermutationStyle ; à réaligner lors d'une prochaine passe pour la lisibilité.
