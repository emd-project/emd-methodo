# Tâches planifiées cloud

Instructions des tâches planifiées migrées de l'app desktop (tâches locales Cowork, abandonnées au 6 octobre 2026) vers des tâches cloud.

Chaque tâche cloud lit le fichier `<nom-de-la-tache>.md` de ce dossier au début de son run et l'exécute. **Pour modifier une tâche, modifie son fichier ici** : le changement s'applique au run suivant, sans toucher à la tâche elle-même.

Le frontmatter (`name`, `description`) est repris tel quel de la version locale.
